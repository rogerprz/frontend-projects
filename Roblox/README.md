## Evidence and priority

01 is the historical Roblox scheduler prompt in your collection. 02–03 have saved Roblox company tags; they are not confirmed current questions. 04–10 are practical frontend builds aligned with the recruiter prep document. 11–16 cover data transformations and JavaScript utilities.

People Feed and Employee Search include HTML/CSS reference pages. React files require a React practice environment. Original source paths and GitHub links remain in comments. Kanban is a new prompt without a reference solution.
